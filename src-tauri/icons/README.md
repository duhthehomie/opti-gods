# Tauri bundle icons

The actual `icon.ico`, `icon.icns`, and `*.png` files are generated by
`cargo tauri icon ../client/public/optigods.png` on the Windows build host
during the CI release job — they are not committed because they're binary
and trivially reproducible. The Windows build pipeline (Task #43) runs the
icon generation step before `cargo tauri build`.

Expected files after generation:
- `32x32.png`
- `128x128.png`
- `128x128@2x.png`
- `icon.icns`
- `icon.ico`
