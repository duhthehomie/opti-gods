# Opti Gods — Social Media Content Audit

## 1. What Opti Gods Is

Opti Gods is a Windows gaming-performance platform built for players who want a faster, cleaner, more responsive PC without blindly running random optimization packs.

It combines:

- Hardware-aware system scanning
- Safe, categorized Windows performance tweaks
- Direct native tweak application in the Windows app
- Individual tweak detection and Undo
- Game-specific performance profiles
- Windows power-plan control
- FiveM Graphics Studio
- AI-assisted recommendations
- Lifetime Pro access
- Automatic signed desktop updates

The product is designed around transparency. Users can see what a tweak does, whether it is safe or advanced, whether it fits their hardware, and whether it is currently applied.

## 2. Who It Is For

Primary audience:

- Competitive PC gamers
- FiveM, Fortnite, Call of Duty, Roblox, Rust, and 007 First Light players
- Users with gaming laptops and prebuilt/OEM PCs
- Players dealing with stutter, input delay, background bloat, weak frame pacing, or incorrect Windows settings
- Users who want guided optimization instead of copying unknown scripts

## 3. Core Brand Position

Opti Gods should be presented as:

- A performance control center, not a “magic FPS button”
- Hardware-aware, not one-size-fits-all
- Transparent and reversible
- Fast and easy enough for beginners
- Detailed enough for advanced users
- Built by gamers for real gaming systems

Brand language:

- Black and red are the core identity.
- Green means a setting is enabled, applied, confirmed, or successful.
- Red means Opti Gods branding, action, energy, and performance.
- The interface should feel compact, premium, technical, and alive.

Avoid unsupported promises such as guaranteed exact FPS gains. Focus on reduced background load, better configuration, cleaner Windows behavior, improved responsiveness, and hardware-specific recommendations.

## 4. Main Product Experience

### Dashboard

The control center for system status, optimization progress, free-tweak allowance, applied changes, account status, and quick actions.

### AI Optimize / System Scan

Scans the user’s hardware and saved system profile, then builds safe recommendations for that specific PC. Automatic recommendations exclude expert-only changes and known high-risk/opt-in settings.

### Tweaks

Organized performance controls for Windows, networking, CPU, GPU, memory, peripherals, debloat, startup behavior, Process Lasso, and process reduction. Supported desktop tweaks apply directly through the trusted native engine.

### Applied Tweaks

A dedicated view of confirmed or session-recorded changes. It distinguishes Windows-confirmed detection from local session history and offers individual Undo controls.

### Power Plans

Reads real Windows power plans and lets desktop users switch the active plan. The app validates power-plan identifiers and uses Windows’ native `powercfg` command rather than simulating state.

### Game Profiles

Game-specific optimization areas for supported titles and apps. These profiles keep game configuration separate from general Windows tweaks.

### FiveM Graphics Studio

Creates client-safe FiveM citizen graphics packs with backup-first installation instructions. It does not claim local control over server time, weather, permissions, or server-side resources.

### Updates

Shows product changes and desktop release status. The signed updater checks GitHub releases and automatically downloads and installs verified newer versions.

### Support and Account

Discord-connected account access, Pro status, help, and product support.

## 5. Free vs. Pro

### Free users

Every authenticated free account receives 15 lifetime performance tweak enables.

Users can:

- Let Opti Gods choose the best safe native tweaks from their saved system scan
- Select eligible tweaks manually
- Apply up to 15 unique performance tweaks
- Undo previously applied tweaks without receiving the credit back

The allowance is account-based and stored on the server. Clearing browser data or reinstalling the app does not reset it.

Only successful native desktop executions consume the allowance. Script downloads do not consume free credits. Free users run their included tweaks through the Windows app.

### Pro users

Pro removes the 15-tweak limit and unlocks the complete optimization platform. Pro follows the connected account rather than a single browser installation.

## 9. Claims to Avoid

Do not claim:

- Guaranteed exact FPS increases
- Control over FiveM server weather, time, permissions, or server resources
- That every tweak works on every PC
- That selected means applied
- That browser scripts are the free-tier execution method
- That risky security changes are automatically enabled

Use measured claims: hardware-aware optimization, fewer unnecessary background tasks, improved configuration, reduced avoidable latency, clearer frame pacing, and a cleaner gaming environment.
