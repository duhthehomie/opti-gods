# Opti Gods V5 Windows Testing Guide

This guide is for measuring real Windows results without mixing server conditions,
graphics settings, or multiple changes at once. Opti Gods does not guarantee a
specific FPS increase. The useful result is the before/after comparison:
average FPS, 1% low FPS, frametime consistency, temperatures, crashes, and
whether the game remained stable.

## What V5 includes

- Hardware scan and hardware-aware recommendations.
- Restore-point-first native Windows execution.
- Full Optimize for Pro users, using the compatible server-authorized preset.
- Best 15 for free Windows users, limited to 15 active native tweak slots.
- Server-authorized one-use native tickets for free and Pro native actions.
- Applied Tweaks run ledger with per-tweak applied, failed, and exact error
  results.
- Native detection after applying changes and after reboot.
- Undo for applied native tweaks where Windows provides a verified undo path.
- NVIDIA performance preset import on one supported discrete NVIDIA GPU without
  hybrid or ambiguous multi-GPU topology.
- MSI Utility v3 High-mode launch guidance on one supported discrete NVIDIA GPU.
  Hybrid and multi-GPU systems remain blocked.
- Backup-first FiveM graphics/input recovery flows.
- Download and updater metadata generated by the Windows release workflow.
- UAC elevation in the packaged Windows app. The installer manifest requests
  administrator consent automatically; users should not need to right-click
  Run as administrator for every launch.

## Important allowance behavior

Free native access is an **active-slot limit**, not a lifetime counter:

- `0 / 15 used` means no free native tweaks are currently active.
- `6 / 15 used` means six free native tweaks are currently active and nine
  additional slots remain.
- A failed native tweak must not consume a slot.
- Undoing an active free tweak releases its slot.
- Duplicate IDs count once.
- A stale or crashed reservation is reclaimed after its recovery window.
- A free run must never execute more than 15 native IDs, even if an old local
  queue contains more.

If the allowance display does not refresh after a result or Undo, wait for the
run to finish and reopen the dashboard. Record the exact count and error text
before attempting another run; do not repeatedly click the action.

Pro Full Optimize is a separate entitlement. Free users receive the
server-validated Best 15 native flow, not the complete Pro preset.

## Before testing

1. Use the latest installer from the Opti Gods Download button or the latest
   verified Windows release artifact.
2. Confirm Windows 10 or Windows 11 is fully booted and connected to the
   internet.
3. Close launchers, browsers, recording software, overlays, RGB tools, and
   background downloads that are not part of the game test.
4. Use the same Windows power mode, GPU driver, game version, display refresh
   rate, resolution, graphics preset, render scale, VSync setting, and FPS cap
   for baseline and replay.
5. Keep the Windows desktop and the game on the same monitor and refresh rate.
6. If the app shows a UAC prompt, select **Yes**. If the prompt is cancelled,
   native changes must be treated as not run.
7. Run the Opti Gods hardware scan and save the detected CPU, GPU list, RAM,
   laptop/desktop state, refresh rate, and hybrid-GPU state.
8. Do not test MSI Utility High mode on a hybrid laptop or a multi-GPU system.
9. Do not run a second optimizer, registry cleaner, driver tweaker, or timer
   tool during this comparison.

## Baseline capture

Use CapFrameX, OCAT, PresentMon, or another frame-time recorder. Record at
least three repeatable runs per game:

| Run | Duration | Avg FPS | 1% low | 0.1% low | Avg frametime | Max CPU temp | Max GPU temp | Notes |
|---|---:|---:|---:|---:|---:|---:|---:|---|
| Baseline 1 | 5–10 min | | | | | | | |
| Baseline 2 | 5–10 min | | | | | | | |
| Baseline 3 | 5–10 min | | | | | | | |

Use the median of the three runs rather than the best run. Record crashes,
stutters, texture pop-in, input problems, network problems, and any unusual
behavior even if FPS looks higher.

## HP Pavilion / FiveM / TMFRZ test

1. Record the exact HP Pavilion model, CPU, GPU, RAM, display refresh rate,
   resolution, FiveM build, graphics pack, and GTA V settings.
2. Join the same TMFRZ server using the same route and character location.
3. Keep the same server conditions as closely as possible: player count,
   weather, time of day, interiors, traffic, and graphics pack.
4. Run the same route for the same duration three times.
5. Capture average FPS, 1% lows, frametime graph, CPU/GPU temperatures, and
   whether input or streaming stutters occurred.
6. Exit FiveM before applying graphics packs or native changes.
7. In Opti Gods, create the restore point, then run the supported compatible
   flow. Record every Applied Tweaks result, including failures.
8. Reboot Windows before the replay.
9. Repeat the same route and conditions three times.
10. If the HP Pavilion is hybrid graphics, do not use MSI Utility High mode or
    the NVIDIA-only preset. Full Optimize must follow the hardware compatibility
    result rather than forcing a GPU-specific action.

## Call of Duty test

1. Record the exact Call of Duty title, mode, map or training scenario,
   renderer, resolution, upscaler, texture settings, frame cap, and display
   refresh rate.
2. Use a repeatable training-range route or the same replay/benchmark if the
   game provides one.
3. Do not compare a quiet menu or private lobby against a live multiplayer
   match.
4. Capture three baseline runs.
5. Apply the eligible Opti Gods flow, record applied and failed results, and
   reboot.
6. Repeat the same three runs with the same settings.
7. Report average FPS and 1% lows together. A higher average with worse 1%
   lows or new stutter is not a successful result.

## Allowance and failure checks

Run these checks once on the test PC:

1. Open the allowance card and record the initial `used / 15` count.
2. Choose **Best 15** once. Do not click twice.
3. On Applied Tweaks, verify each row ends as applied or failed.
4. Confirm the final active count equals the number of successful active free
   native tweaks, never more than 15.
5. If one row shows `OG-HTTP-400 · Ineligible tweak`, leave it visible in the
   run ledger and record its tweak name and exact message. It is a failed
   result, not an applied tweak.
6. Undo one confirmed tweak. Verify the active count decreases by one.
7. Run Best 15 again. Verify the released slot can be reused and that
   already-active IDs are not charged twice.
8. Restart the app and verify the count remains correct.
9. If the browser or app closes during a run, wait at least 15 minutes before
   interpreting a stale reservation as a permanent allowance loss.

## NVIDIA-specific checks

Only perform these checks when the scan reports exactly one discrete NVIDIA GPU
and no hybrid-GPU ambiguity:

1. Confirm the app shows the supported NVIDIA preset action.
2. Confirm a restore point exists before import.
3. Run the verified NVIDIA preset once.
4. Treat a non-zero Profile Inspector exit as a failure; do not report it as
   applied.
5. For MSI Utility v3, select only the active NVIDIA adapter, choose High, and
   press Apply. Driver updates can reset this setting.
6. Do not claim driver readback or FPS improvement solely because the utility
   opened successfully.

## Stop conditions

Stop the test and use the Windows restore point if any of these occur:

- BSOD, repeated reboot, boot failure, or Windows Recovery screen.
- FiveM or Call of Duty crashes repeatedly after the change.
- Network disconnects or server instability that did not occur in baseline.
- Severe input delay, mouse/keyboard failure, black screen, or display loss.
- Temperatures or clocks become abnormal for the hardware.
- Opti Gods reports success while Windows detection or the run ledger reports
  failure.

Do not continue stacking tweaks after a stop condition. Capture the error code,
exact tweak name, Windows version, driver version, and the diagnostic log first.

## Results to send back

Send:

- PC model and complete hardware scan.
- Windows build and GPU driver version.
- Game settings and test scenario.
- Three baseline rows and three replay rows.
- Average FPS, 1% low FPS, frametime notes, and max temperatures.
- Applied Tweaks results, including exact failures.
- Final free allowance count.
- Whether a reboot occurred between apply and replay.
- Any crash, stutter, input, display, or network change.

Do not report “max FPS” from one run. Report the median before/after result and
whether stability improved, stayed equal, or got worse.
