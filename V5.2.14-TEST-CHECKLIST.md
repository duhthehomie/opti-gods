# Opti Gods v5.2.17 release test checklist

Run this list against the tagged Windows installer before posting the download
link publicly. The installer must come from the GitHub Actions run for the
same commit that contains this checklist and the v5 fixes.

## Release identity

- [ ] Installer filename is `OptiGods-Setup-5.2.17.exe`.
- [ ] Windows installer version and in-app Account version both show `v5.2.17`.
- [ ] GitHub Release tag is `v5.2.17`.
- [ ] Release includes `latest.json`.
- [ ] `latest.json` version, notes, URL, size, and SHA-256 match the uploaded EXE.
- [ ] The EXE SHA-256 is recorded before posting the link.
- [ ] The EXE is the asset from the successful GitHub Actions run, not a local
      build or an older `downloads/` copy.

## Clean signed-out browser state

- [ ] Open a private/incognito browser window.
- [ ] Confirm `/api/me` reports no user and `/api/pro/status` reports
      `isPro: false`.
- [ ] Open the dashboard in guest browse mode.
- [ ] Full Optimize / Enable Best 15 action buttons are not rendered while
      signed out.
- [ ] Tweak pages remain browseable, but applying/authorizing requires the
      correct account or Windows app path.
- [ ] Account shows `Guest / Code session` and `Free tier`, never
      `Opti Gods Pro` or `ACTIVE`.

## Discord login and Pro session

- [ ] Sign in with Discord and confirm Account shows the correct Discord
      profile.
- [ ] Redeem a valid Pro code.
- [ ] Confirm the Pro badge appears without a full page refresh.
- [ ] Open Dashboard, AI, and Pro-only pages and confirm Pro access is present.
- [ ] Sign out from Account.
- [ ] Confirm the redirect lands on the public page.
- [ ] Confirm local Pro token is gone, `/api/me` is unauthenticated, and
      `/api/pro/status` is `isPro: false`.
- [ ] Return to Account after sign-out: it must show Guest / Code session and
      Free tier with no `ACTIVE` badge.
- [ ] Close and reopen the browser; signed-out state must remain signed out.
- [ ] Sign in again and confirm a Discord-linked entitlement returns Pro access.

## Windows native app login/logout

- [ ] Install v5.2.17 on a clean Windows test machine.
- [ ] Sign in from the desktop app and confirm the session survives app restart.
- [ ] Run Account → Sign out.
- [ ] Confirm the Windows credential session and native auth token are cleared.
- [ ] Confirm the app returns to its sign-in screen and does not restore Pro
      from a stale code token.
- [ ] Sign in again and confirm the account is restored normally.

## Hardware scan and recommendations

- [ ] Run Instant Scan on a real Windows PC.
- [ ] Confirm the scan completes, plays the success sound, and displays the
      detected GPU, CPU, RAM, OS, and device data.
- [ ] Confirm the validated scan is accepted by the server.
- [ ] Refresh the page and confirm the scan remains available.
- [ ] Confirm recommendations match the detected GPU vendor and Windows
      version.
- [ ] Confirm unsupported or unsafe tweaks are withheld instead of listed as
      applicable.
- [ ] Confirm stale/incomplete scan errors explain how to rescan.

## Full Optimize / Best 15

- [ ] With a valid Pro account and validated scan, run Full Optimize.
- [ ] Confirm there is no 409 response and no “Could not build your hardware
      preset” error.
- [ ] Confirm the native app creates or verifies the restore point before
      applying changes.
- [ ] Confirm the app navigates to Applied Tweaks and reports each tweak as
      applied, skipped, or failed truthfully.
- [ ] Confirm a second run does not claim already-confirmed tweaks were newly
      applied.
- [ ] With a free eligible account, run Best 15.
- [ ] If fewer than 15 compatible tweaks remain, confirm the available valid
      tweaks are offered instead of a misleading 409.
- [ ] If zero eligible tweaks remain, confirm the error explains that the user
      must undo an active tweak or rescan.
- [ ] Confirm allowance usage changes only after native execution succeeds.
- [ ] Confirm Undo does not consume another allowance slot.

## AI and sound

- [ ] Run Instant Scan from the AI/system scan page.
- [ ] Confirm the completion sound plays after a successful native scan.
- [ ] Confirm failed scans use the error sound and show the actual reason.
- [ ] Confirm AI Smart Preset resolves for the scanned hardware.
- [ ] Confirm AI does not recommend vendor-incompatible or blocked tweaks.

## Publish and download

- [ ] Run the Replit publish build only after the EXE release is verified.
- [ ] Confirm the publish build runs the deployment cleanup before compiling
      and finishes below the 7 GiB safety threshold.
- [ ] Confirm the live Download button resolves to the v5.2.17 GitHub Release
      asset.
- [ ] Download once from the live site and compare its SHA-256 to the release
      checksum.
- [ ] Do not post the public download link until every release identity,
      logout, scan, Full Optimize, and checksum item above passes.
